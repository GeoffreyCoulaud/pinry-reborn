## 1. Goal

The API stores its data in PostgreSQL, run as a service beside it, and SQLite leaves the repository. Behaviour is
unchanged but for one widening: a name or a description compares without case in every script, where it did in ASCII
alone. The backlog's P2 item "SQLite changes a referenced table's column only by a rebuild" closes.

## 3. Decisions

The operator's answers in the Discuss of 2026-10-11 and 2026-10-12, the letter of the question in brackets, unless a
decision says it is the lead's. Tier: Spec (A).

**B. PostgreSQL replaces SQLite.**
- `ebean-sqlite` and `sqlite-jdbc` leave; `io.ebean:ebean-postgres` at the pinned Ebean version and
  `org.postgresql:postgresql` 42.7.14 enter.
- The baseline is generated again on `PostgresPlatform`, every file of `mig/` replaced, and stays append-only from
  this lot's merge. A development database is created afresh; nothing is migrated from a SQLite file.
- The four hand-written `CHECK` constraints are carried into it; `ck_media_variant` reads `mime_type like 'video/%'`,
  case-sensitive on that column as `glob` was.
- PostgreSQL 18.6, pinned once, in `compose.yml` by tag and digest. Dagger reads it there, as it reads the proxy's; a
  test refuses an `ebean.test` version that differs from its tag.
- The database is initialised with `--locale-provider=builtin --locale=C.UTF-8` (`POSTGRES_INITDB_ARGS`) in
  `compose.yml` and the gate's services, and in ebean-test's container if its configuration carries initdb arguments;
  if not, the workstation's container keeps the image's default, no ordering of the suite depending on it (the lead's).

**C. Still one connection.** `minConnections` and `maxConnections` stay 1 in the three datasources. A test reads the
pool's maximum in each suite, ebean-test rewriting the address and not the pool. One API process is an assumption
`compose.yml` keeps and nothing enforces (ADR 0059, decision 2). The backlog gains the pool as a P2 item.

**D. ebean-test reaches PostgreSQL.**
- `ebean-test` enters `api-application`'s tests. `ebean.test.platform=postgres`, `ddlMode=migrations`, so the suites
  run the baseline as production does.
- Each suite has its own database, `pinry_persistence` and `pinry_application`, so the two suites never share one.
  Two checkouts on one workstation do share ebean-test's container: accepted.
- On a workstation ebean-test starts the container. In the gate, `gradle()`'s test runs get two PostgreSQL services,
  one per suite, each created by the image from its `POSTGRES_DB`, `POSTGRES_USER` (the database's name) and
  `POSTGRES_PASSWORD` (`test`), the user owning the database and its `public` schema. Environment variables turn
  `useDocker` off and name each address; the test properties read them with the workstation's values as defaults.
- The tables are emptied before each test in one `truncate ... cascade` statement over every table but
  `db_migration`. The pull request of block 50 records the gate's duration before and after.

**E. A text compares without case through its column's collation.**
- Ebean's `extra-ddl.xml` declares an init script for PostgreSQL, `create collation if not exists case_insensitive
  (provider = icu, locale = 'und-u-ks-level2', deterministic = false)`, which runs before the baseline.
- The column declares it in `@Column(columnDefinition = ...)`: in block 50 `users.name`, `boards.name`, `tags.name` and
  `persons.name`, whose four unique indexes lose `collate nocase`; in block 60 `pins.description` and
  `remote_collections.name`, the columns searched or sorted for a reader.
- Every lookup by name is `eq`; `ieq`, `icontains` and `istartsWith` are not used on a collated column. The two
  in-memory sorts move into the query. `RawSqlOutsideInventory` loses the `collate nocase` and `glob` entries:
  `EbeanMediaRepository` uses the query beans' `startsWith("video/")`, `LIKE` being case-sensitive on `mime_type`.
- Searches keep `contains` and `startsWith`, the column carrying the fold. Ebean's `expressionNativeIlike` stays off:
  `ILIKE` refuses a nondeterministic collation.

**F, K. Native types.** `uuid`, `boolean`, `bigint` and `timestamptz` come from `PostgresPlatform` with no annotation.
`persons.urls` stays canonical JSON text (K) and `tasks.payload` an opaque string. A person's unique index reads
`(author_id, name, md5(urls))`, an index entry being bounded at 2704 bytes (block 80).

**G. PostgreSQL is a service of its own.**
- `compose.yml` runs `postgres` on its own volume, with a health check the API waits on.
- Production reads `DB_URL`, `DB_USERNAME` and `DB_PASSWORD`. A startup check refuses to boot when `DB_PASSWORD` is
  unset and names it, avaje-config leaving an unresolved placeholder as its literal text (block 90).
- `dagger call smoke` and the compose smoke start the API with a bound PostgreSQL service.
- The `Dockerfile` loses `DB_PATH`, and `/data` keeps the media and the archives. `--enable-native-access` leaves
  the entry point and the test JVMs.

**H. The module is `api-persistence-ebean`**, package `...persistence.ebean`; the detekt baselines follow the module's
name. `SqliteConstraintViolations` becomes `ConstraintViolations` in block 70.

**I. Similarity search stays out**: its own lot. Block 100 rewords the backlog item, which no longer waits on an
engine.

**J, L. `PersonName` compares its text as written.** Its KDoc and `Person`'s stop naming a fold; `PersonNameTest` and
the import fixtures' fake follow. `agents/data-modelling.md`'s rule becomes "**The domain never folds more than the
database does**: a fold it cannot reproduce is left to the database, through a find-or-create." (L, in the operator's
words: concise.)

**M. A violation is translated only when it names the constraint the caller expects** (lead's). The caller passes
the constraint's name; `ConstraintViolations` reads it from `PSQLException.serverErrorMessage.constraint` and rethrows
any other violation, the primary key's included. The four unique indexes named `*_nocase` take a name without it
(`ux_users_name`, `ux_boards_author_name`, `ux_tags_author_name`, `ux_persons_author_name_urls`), and
`UniqueConstraintOutcomeTest` follows.

**N. The task queue's deduplication declines the collision** (lead's). The insert is a raw
`insert ... on conflict do nothing`, in the inventory with its reason, then the live task is read. No conflict target:
`ux_tasks_dedup` is partial, and Ebean's `InsertOptions` always names a target, which PostgreSQL then refuses. The
bare form would also absorb a primary-key collision, which a fresh `randomUUID()` rules out. SQLite has accepted the
statement since 3.24, so it lands before the switch (block 40). `onUniqueConstraint` leaves the code with its caller.

**O. A login name outside the account alphabet resolves to no account** (lead's). `UserAuthenticator` reads no user
for a name outside `^[A-Za-z0-9._-]+$` and answers as for an unknown name: the dummy hash, the failure counted, 401.
The key is unchanged, a function of the string. Over the alphabet `lowercase(Locale.ROOT)` and the collation agree;
outside it the collation's width fold would reach an account (`ａｄｍｉｎ` is `admin`) under a key of its own. The
pattern moves to the domain, read by `UserInputDto` and `UserAuthenticator`.

**P. An imported instant is restored at the millisecond** (lead's). `ImportInstantClamp` truncates, as `SystemClock`
does, so an archive's sub-millisecond instants do not survive into PostgreSQL's microseconds and out again (block 40).
`SystemClock` keeps the millisecond. `PinIdsInputDto.MAX_IDENTIFIERS` stays 10 000, under PostgreSQL's 65 535 bound
parameters.

## 4. Data shape

The archive changes nowhere: `ExportContentGoldenJsonTest`'s expected text is unchanged at every block. The wire
changes in descriptions alone (block 60).

| Datum | Domain type | Optional | Identity and uniqueness | Storage | Wire | Archive |
|---|---|---|---|---|---|---|
| A user's, board's, tag's or person's name | unchanged; `PersonName` compares as written | unchanged | per author (users: global), case and width folded in every script | the `case_insensitive` collation | unchanged; the descriptions say "case folded" | unchanged |
| A pin's description, a remote collection's name | `String`, unchanged | unchanged | None: not an identity | the `case_insensitive` collation | unchanged | unchanged |
| An identifier | `UUID`, unchanged | unchanged | unchanged | `uuid` | unchanged | unchanged |
| A boolean column | `Boolean`, unchanged | unchanged | None: a fact | `boolean` | unchanged | unchanged |
| An instant | `Instant`, unchanged | unchanged | None: a fact | `timestamptz`, at the millisecond | unchanged | unchanged, imports truncated to the millisecond |
| A person's addresses | `Set<HttpUrl>`, unchanged | no | with the name, per author, through their digest | canonical JSON text, unchanged | unchanged | unchanged |
| A task's payload | `String`, unchanged | no | None: the task's | text, unchanged | None: not on the wire | None: tasks are not exported |
| A login attempt's key | `AuthenticationAttemptKey`, unchanged | no | the submitted name, lower-cased | None: memory alone | None | None |

Rules this table follows, from `agents/data-modelling.md`: a standard type first, a type never carries a storage
format, a list in one column is canonical JSON, the domain never folds more than the database does (as amended in
block 30), alpha data is disposable.
