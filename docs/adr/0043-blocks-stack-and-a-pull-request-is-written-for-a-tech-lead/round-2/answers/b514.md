# b514

1. **Contexte.** L'API sert l'export et l'import depuis un moment, mais aucun client ne les appelle encore : ce lot les amène sur l'écran de compte de la web application, et cette PR en est le côté API (plus la spécification du lot). Il manque deux choses au client : le `state` d'un export ou d'un import est publié comme une simple chaîne, donc le client ne connaît pas les états possibles, et la taille des morceaux d'upload (16 MiB) comme la borne d'archive (20 GiB) vivent dans la configuration `imports.*` sans être publiées nulle part.

2. **Pourquoi.** Les écrans de ce lot en dépendent : le client décide sur `state` s'il interroge à nouveau, quels boutons il montre et si un lien de téléchargement existe, et un état inconnu n'a pas de défaut correct. Sans les bornes publiées, le client devrait coder la taille en dur dans le bundle, qui divergerait d'un déploiement qui les abaisse. Le moment est celui où le premier client consomme ces endpoints ; la description ne donne pas d'autre urgence.

3. **Comment.** Les deux `state` deviennent des `enum` dans le contrat via des jumeaux de présentation des enums du domaine (forme de `DownloadStatusDto`) mappés par un `when` exhaustif, alors que `kind` et `failureCode` restent des chaînes ouvertes, car les fermer ferait de chaque nouvelle anomalie un major, figé après la bêta ; un test de contrat fige ce partage, et le contrat passe de `17.0.0` à `18.0.0` puisque `oasdiff` lit l'ajout d'un enum de réponse comme une rupture. Les bornes rejoignent `LimitsDto` du handshake (`maxImportChunkBytes`, `maxImportArchiveBytes`) en suivant le chemin que `maxArchiveBytes` prend déjà : `ImportsConfig` (worker) vers `ImportProducers` (composition root) qui produit `ImportUploadBounds` (usecases), lu par `HandshakeController`, sans nouvelle dépendance entre modules. L'alternative évidente, un second `@ConfigMapping` sur `imports.*` dans le module de présentation, aurait déclaré chaque défaut deux fois ; un test d'intégration qui surcharge les deux clés empêche une constante en dur dans le contrôleur.
