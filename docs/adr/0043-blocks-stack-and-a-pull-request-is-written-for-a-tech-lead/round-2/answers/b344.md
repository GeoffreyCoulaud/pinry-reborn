# b344

## 1. Context

The API has served export and import for a while (twelve operations under `/api/v1/me/exports` and `/api/v1/me/imports`), but the web application calls none of them. The lot "the data travels" brings both to the account screen and the task centre as a stack of six pull requests, and this one is the bottom: it changes only the contract (plus the lot's specification). What is missing is that the export and import `state` fields are published as plain strings, and the import's chunk size and archive bound (`imports.*`, 16 MiB and 20 GiB by default) are published nowhere.

## 2. Why

The five client blocks above need to be typed against these facts: the client's behaviour (whether to poll, which buttons to show, whether a download link exists) hangs on `state`, and an unknown state has no correct default, so the set must be closed. The client needs the chunk size to cut its uploads and the archive bound to refuse a file before opening an import; hard-coding them in the bundle would drift from a deployment that lowers the keys. Without this block the client blocks cannot be built type-safely. The description does not say why this lot is being done now rather than earlier, beyond the web application not yet using these endpoints.

## 3. How

The two states get presentation-layer DTO enums mirroring the domain enums (as `DownloadStatusDto` already does), mapped by an exhaustive `when` so a new domain state breaks the build instead of reaching clients silently; fields that only pick a sentence (`kind`, `failureCode`) stay open strings, since closing them would make every new anomaly a contract major. The bounds live in `ImportsConfig` in the worker module, which presentation may not depend on, so the composition root (`ImportProducers` in `api-application`) produces an `ImportUploadBounds` in `api-usecases` that `HandshakeController` reads into two new required `LimitsDto` fields, the same path `maxArchiveBytes` already takes, adding no module dependency. The obvious alternative, a second `@ConfigMapping` on `imports.*` in presentation, is rejected because it would declare every default twice. The contract goes from 17.0.0 to 18.0.0 because `oasdiff` counts an enum in a response as breaking, which the alpha allows (nothing is frozen), and tests pin the published enums to the domain entries, `kind` to an open string, and the handshake to overridden `imports.*` values.
