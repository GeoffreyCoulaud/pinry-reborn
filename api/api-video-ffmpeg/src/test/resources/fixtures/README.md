# Video fixtures

Generated by ffmpeg's `lavfi` sources, from this directory. `playlist.m3u8` is written by hand: an HLS playlist
whose one segment is `mpegts.ts`.

```bash
V=(-f lavfi -i testsrc2=size=160x120:rate=10:duration=1)
A=(-f lavfi -i sine=frequency=440:duration=1)
ffmpeg -y "${V[@]}" "${A[@]}" -c:v libx264 -c:a aac h264-aac.mkv
ffmpeg -y "${V[@]}" -c:v libx264 mpegts.ts
```
